# Farm Assistant

面向 Farming Season 的浏览器自动化研究项目，包含农务规划、页面操作、战斗输入与结算数据观察。当前版本：**1.25.2**。

> **仅供学习、研究与交流。** 本项目为个人研究项目，与 Farming Season 官方无隶属关系。如涉及侵权，或对游戏、玩家及其他相关方造成损害或不当影响，请通过 [GitHub Issues](https://github.com/Gintma/Farm-assistant/issues) 联系维护者；核实后将配合修改、下架或删除相关内容。

## 功能概览

| 模块 | 功能 |
| --- | --- |
| 田地 | 收获与补种、作物选择、保留能量、按每日额度安排种植 |
| 动物 | 喂养、收集产品、饲料与材料保留安排 |
| 作坊 | 按订单安排加工、次日备货、比较缺料采购与加工成本 |
| 日常 | 村庄收入、矿场、油井、钓鱼等已开启任务 |
| 收益 | 查看收获、战斗与作坊订单的今日完成情况及额度明细 |
| 战斗 | 寻敌、走位、闪避、风暴、升级选择、可选的目标金币退出、导出最新结算 |

面板支持拖动、收起和执行状态显示。具体行为、适用条件与配置说明见 [详细安装说明](extension/安装说明.md)。

## 安装

支持桌面版 Chrome / Brave，需要允许加载未打包的扩展。仓库已包含构建结果，使用时无需安装 Python 或 Node.js。

1. 获取代码。推荐通过 Git 克隆到一个长期保留的目录：

   ```sh
   git clone https://github.com/Gintma/Farm-assistant.git
   ```

2. 打开扩展管理页：Chrome 使用 `chrome://extensions`，Brave 使用 `brave://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择仓库中的 **`extension` 文件夹**。
4. 打开游戏，通过扩展按钮开启助手，按面板提示完成版本检查，再按需开启功能。

也可以下载 GitHub ZIP 并解压安装，但 ZIP 目录不能使用下面的 Git 更新方式。安装后请保留原目录，避免反复删除、重新安装扩展。

## 更新

Mac 可双击仓库根目录的 **`更新助手.command`**。如果无法直接运行，在仓库目录执行：

```sh
sh 更新助手.command
```

其他系统可在仓库目录执行：

```sh
git pull --ff-only origin main
```

拉取完成后，等当前战斗结束、农务操作完成，在扩展管理页点击「重新加载」，然后刷新游戏并核对版本。遇到未知游戏更新时，先核对变化，再按面板提示确认兼容。

Git 只同步代码，不会自动重载扩展，也不会同步两台电脑的设置。每台电脑需要分别更新。一键更新只允许 `main` 分支快进；发现本地修改或历史分叉时会停止，避免覆盖改动。

## 使用要点

- **按需开启任务。** 涉及金币消耗的功能，请先了解对应配置与采购规则。
- **战斗由用户手动开局。** 自动战斗不会重复开局；刷新后需要重新开启。
- **目标金币退出单独控制。** 默认值为今日战斗上限减本局开始前今日累计，开局后固定。输入有效的非负整数即更新目标，只有目标开关开启时才会到额退出；开关默认关闭。
- **Esc 停止自动操作。** 页面隐藏、验证弹窗或手动接管等情况，会按相应规则暂停。
- **农务设置保存在浏览器本地。** 原安装目录、原浏览器配置下更新通常可保留设置；从旧扩展或其他目录迁移时，建议先记下配置。

## 实现与数据

农务功能读取当前游戏状态，复用页面既有操作流程；战斗移动与技能通过 Chrome 调试接口发送键盘输入，保持游戏原有伤害、冷却和结算逻辑。自动化输入仍是自动化，项目不承诺收益、持续兼容或账号安全。使用前请确认适用的授权范围与平台规则，人机验证由用户自行处理。

扩展申请 `activeTab`、`debugger`、`storage` 权限，用于当前游戏页操作和本地设置。战斗自动输入或测试记录期间，浏览器顶部会显示调试提示。

「导出最新结算」只保留当前标签页最新一次脱敏结算上报，新上报会覆盖旧记录，刷新后仍可导出。记录包含结算请求正文和部分响应结果，不保存请求头或 Cookie，局标识等敏感字段会脱敏。网络失败或服务器拒绝也会记录，发起上报不代表结算成功。该功能不修改、不重放请求。

扩展另提供可选测试记录：手动对照会关闭自动功能，助手测试保留原开关。详细的数据范围与限制见 [安装说明中的测试记录](extension/安装说明.md#测试记录)。

## 开发与维护

```text
src/                 功能源码
extension/           浏览器加载目录，包含已构建文件
scripts/build.py     构建脚本与版本配置
tests/               回归测试
更新助手.command      Mac 更新入口
AGENTS.md            仓库维护约定
```

开发环境需要 Python 3 和 Node.js 20 或更新版本。修改 `src/` 后执行：

```sh
python3 scripts/build.py
python3 -m unittest discover -s tests -v
```

缺少 Node.js 时，相关回归检查会跳过。构建会更新 `extension/launcher.js`、扩展版本，并在本地生成 `dist/` 产物；不要直接编辑生成的启动文件。

发布功能更新时，同步构建脚本、README 与安装说明中的版本号，提交源码、测试及对应的扩展构建结果。不要提交账号快照、网络记录、钱包或登录资料、原游戏资源、研究抓取或浏览器配置。更多要求见 [AGENTS.md](AGENTS.md)。
