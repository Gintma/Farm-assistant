# Farm-assistant

Farming Season 农场助手，目前版本 **1.25.1**。包含田地、动物、作坊、次日订单备货、日常、收益进度与战斗功能。

战斗页新增「导出最新结算」，自动观察本页 `POST /api/farm/battle/end` 的请求正文副本与响应结果，不需要另开测试记录。包含本局金币、击杀、波次、时长、死亡标记、`stats`（含 `sig`）、`dbg`、`px` 等已上报字段；身份凭据和局标识脱敏，不存请求头或完整账号响应。只保留当前标签页最新一份，新的结算上报覆盖旧记录；刷新后仍可导出，回村后战斗标签仅保留导出入口，不显示战斗控制。记录网络失败和服务器拒绝，不把发起请求当成已成功结算；不会修改或重放请求。

修复按键发送与升级弹窗/游戏暂停撞在一起时误关「自动战斗」开关：临时不可输入只松键等待，恢复后继续，原升级开关也保留。标签页未激活和已取消的过期输入同样按等待处理；连接被关闭、事件未送达、版本不匹配等真实故障仍关闭战斗并显示原因，不自动重连。

战斗页已删除实时 `keys` 显示及对应读取代码，结算与导出统计仍由游戏正常生成。目标金币改为输入框加独立开关，不再显示“应用/恢复默认”按钮；开关默认关闭，有效非负整数输入后直接生效，空值或无效值不沿用旧目标执行。默认值仍按今日战斗上限减本局开始前今日累计，开局后固定；开启后按本局收益到额退出，关闭时不因目标退出。Esc同时关闭自动战斗和目标退出，刷新后目标开关关闭并恢复默认计算。

本版将战斗移动、闪避和风暴统一为 Chrome 调试接口派发的键盘自动输入，不再驱动页面内部按键对象或直接调用技能方法。游戏自行采集原始按键、间隔与技能统计；不补写 `keys`、不改 `stats.sig` 或事件属性。这是自动化输入，不代表真人，也不能保证平台接受或不会封禁。

战斗自动输入期间保留顶部调试提示；停止输入后释放键盘连接，记录器仍在运行时保留录制连接。两者共享同一标签页的调试连接，停止其中之一不会中断另一项。输入失败、调试连接被手动关闭时停止自动战斗，断连后不立即自动重连；清理已按住的键，绝不回退到内部控制。网页刷新后仍需手动开启战斗，农务及游戏代码检查的原设置保留。更新时需重新加载扩展并刷新游戏，让内容脚本与页面控制层同时升级。本版只做本地模拟与回归，不代用户开启实号战斗。

弓箭手改为只躲已射出的箭：瞄准、锁定与射箭蓄力不再生成假想箭矢或避让路线，所有波次一致。箭实际出现后，继续按当前位置、速度和角色移动路线预测碰撞，并纳入多箭交叉火力与赶路闪避检查。Boss、炸弹、近战、火球与低血量规则保留，输入与上报不变。此版已通过本地回归，未进行实号战斗验证。

已适配6/7级与新的单张订单奖励上限。6/7级沿用5级收益、能量价格和动物容量规则，按实际雇用数量调度最多7/8名农夫，不自动升级或雇人。单张订单最多为每日订单额度的三分之一（向下取整），4张订单仍按3作分母；采购利润、追加投入和收益明细都纳入该限制，继续先用库存、保留10%余量，纯星星开关与已记账成本不重置。

战斗加强Boss与小怪混战、门口拥挤时的撤离和目标路线判断。低于或等于55%生命、附近怪群密集时保留赶路闪避；存在安全步行路线时优先走位，紧急爆炸等仍可闪避。需要全速撤离时避免启动减速的风暴。保留随机安全等待区域、原升级优先级、本局金币目标和结算后5秒回村庄。测试覆盖新战斗统计的正常提交，统计仍由游戏生成；本版不接入官方托管助手，不改变游戏受伤、冷却或结算逻辑。未进行实号战斗验证，不能保证任何局面都存活。

新增面板顶部的「游戏代码检查」开关，默认开启，暂停遮罩出现时也可操作。关闭后停止代码扫描与接口兼容性观察，忽略所有更新及兼容性暂停，原已开启任务可继续；同一浏览器配置刷新后保留选择。重新开启立即核对当前版本，原版本基准与异常记录保留，不会自动确认兼容。游戏自己的更新/刷新机制及各任务的数据、预算和人工暂停规则照常生效。

本版适配果汁压榨坊与第4张订单：按已开启的规则显示3或4张订单，支持果汁解析、交单、成本记录和次日预测；2份果树水果加工40分钟得到1瓶果汁，已有库存和排队产出优先抵扣。按今天及次日订单缺口保留水果、采集成熟果实，不把浆果当作榨汁材料。市场比较买成品果汁与买水果加工的总增量成本，沿用真实奖励、历史投入、加工能量和10%余量约束。

**没有压榨坊或果园不会卡住其他任务。** 有利润且已开启采购时可直接买果汁；只有压榨坊也可买水果加工；有库存果汁可直接交单。否则仅缺料订单等待，其他订单和农务继续，不反复打开订单板，不自动购买建筑、果园或树木。订单增加不代表每日金币上限增加；收益页按实际数量显示完成进度，纯星星交单也及时刷新。

本版修复收获满额后仍自动钓鱼：每竿重新读取含有效奖励比例、NFT、银行及饲料返还的共享收获额度，满额时不买饵、不抛新竿。改用游戏单竿按钮，先用剩余鱼饵，不足才补购，维持每日最多购买20个、最多20竿。已抛出的本竿正常收尾；旧版正在运行的整批钓鱼通过游戏“钓完这条后停止”按钮请求结束，不清空或改写游戏队列。原开关保留，额度恢复后继续。

本版将收益页收敛为三项「今日完成情况」：收获、战斗、作坊订单。精确额度放在「额度明细」，游戏已有的余额、能量、奖励比例、NFT加成、补足额度与经济规则不再重复展示。账号订单额度和全服预算分开判断；全服预算耗尽时不会提示仍可获金币。收益页的执行状态默认折叠，异常保持展开；其他页保留当前动作、等待原因与下一步，材料和记录放入执行详情。标题与标签固定，内容在面板内滚动，保留拖动和收起。

检查开启时，游戏更新检测分两层：已核实的缓存包装器变化与收录在审核目录中的特定文案更新自动放行；未归类的代码、规则或模块变化仍暂停全部自动功能，需核对后确认。不会凭「上报字段没变」断定没有兼容性变化或没有检测逻辑。

检查开启时执行只读接口校验，发现已覆盖接口的关键字段/类型异常时暂停相关功能；市场问题不暂停田地，订单问题不暂停战斗。已覆盖的 GET 响应异常连续两次恢复正常后可以解除对应暂停；按钮只执行相关 GET 重查，不发送或重放操作。所有原开关保留，不自动刷新、开局或确认未知版本。

观察范围是已列出的同源 fetch JSON 接口与部分关键字段，包含农场、操作队列、订单预算、市场和战斗请求；不是全部网络监控，也不能证明服务端校验逻辑没变。不保存请求体、响应体、请求头或身份信息，只保存异常类别和说明。价格、奖励与配方的未知静态代码变化仍按未知更新处理；动态报价沿用提交前重算、预算与利润检查。详见安装说明。

## 两台电脑首次安装

每台电脑各安装一次 Git，并在希望长期保存助手的位置打开终端，执行：

```sh
git clone https://github.com/Gintma/Farm-assistant.git
```

如果仓库设为私有，需要使用有访问权限的 GitHub 账号登录。不要把密码、访问令牌或钱包资料写进代码、仓库地址或说明文件。

打开 Chrome 的 `chrome://extensions`（Brave 使用 `brave://extensions`），开启开发者模式，点击“加载已解压的扩展程序”，选择下载目录里的 **extension** 文件夹。不要选择整个仓库。

从旧 ZIP 版迁移时，请先在原助手里记下开关和配置，再停用旧扩展，加载新目录。首次更换安装路径可能产生新的扩展身份，原设置不一定自动迁移；目前没有设置导入功能。迁移完成后一直保留同一个目录和扩展，不要重复删除安装。

Mac 双击“更新助手.command”可更新。如果 Finder 不允许执行，可在终端进入仓库后运行：

```sh
sh 更新助手.command
```

## 以后更新

1. Mac 双击 **更新助手.command**；其他系统在仓库里执行 `git pull --ff-only origin main`。
2. 等战斗结束、农务操作完成，在浏览器扩展管理页点击助手的“重新加载”。
3. 刷新游戏，核对版本。游戏代码检查开启时，已核实的缓存/文案变化自动放行；未知更新按面板提示核对兼容后确认。关闭时保留关闭状态。

**Git 同步代码，不自动重新加载浏览器扩展。** 每台电脑需分别更新。后续在相同目录、相同浏览器配置下更新，账号设置保留；设置不会通过 Git 在两台电脑间同步。

一键更新仅允许 main 分支快进，有本地修改或历史分叉就停止，不强制覆盖。直接下载 GitHub ZIP 不包含 Git 历史，不能使用这个更新入口。

## 给维护者 / AI

- `src/`：18 个功能模块，编辑这里。
- `extension/`：浏览器加载的固定目录，包含已构建的启动文件。
- `scripts/build.py`：拼接模块、同步版本、生成 ZIP。
- `dist/`：本地生成的 ZIP 和独立启动脚本，不提交 Git。
- `extension/安装说明.md`：功能和运行规则说明。

修改代码后执行：

维护电脑需安装 Python 3；安装 Node.js 20 或更新版本才能同时运行战斗回归检查，缺少 Node 时会显示跳过。使用电脑只需 Git 和浏览器。

```sh
python3 scripts/build.py
python3 -m unittest discover -s tests -v
```

发布前更新构建脚本中的版本号，并同步 README 和安装说明；提交 `src/` 与构建后的 `extension/`。其他电脑只拉取发布文件，不需要安装 Python 或 Node。

```sh
git add src extension scripts tests README.md AGENTS.md .gitignore 更新助手.command
git commit -m "Release helper update"
git push origin main
```

只上传助手自己的代码、说明和测试。不得提交账号快照、网络记录、钱包/登录数据、原游戏资源、研究抓取或浏览器配置。当前仓库不包含单独的快速战斗项目。
